# ЛР3. Два лимита через общий интерфейс

Вариант: **Limits**.

## Что дано

Предметные объекты, внешний API и вспомогательные типы уже подготовлены. В `app/domain/rules.py` даны заготовки общего интерфейса и двух исполнителей. Их поведение и основной метод `LimitsService.check()` требуется завершить самостоятельно. Сигнатуры сохранены; новые слои и выбор архитектуры не нужны.

## Задание

### Шаг 1. Реализуйте общий интерфейс и два поведения

Оформите `LimitRule` как абстрактный класс с `check(context) -> CheckResult`.

`TransactionLimit` проверяет `amount <= maximum`, иначе возвращает `TRANSACTION_LIMIT_EXCEEDED`. `DailyLimit` проверяет `projected_today() <= maximum`, иначе возвращает `DAILY_LIMIT_EXCEEDED`.

`maximum` — готовый неотрицательный `Money` в валюте контекста. Ноль запрещает любую положительную покупку. Сервис вызывает правила по порядку и возвращает первый отказ; стандартные правила пока можно создавать в сервисе.

### Шаг 2. Соберите путь вызова в `LimitsService.check()`

Сначала проверьте тип `LimitCheckContext` (`INVALID_CONTEXT`). Затем вызывайте правила по порядку, проверяйте тип `CheckResult` (`INVALID_RESULT`) и возвращайте первый отказ. Накопленные суммы не меняйте. Не выбирайте алгоритм по конкретному классу исполнителя.

### Шаг 3. Проверьте повторное использование

При расходах 950 покупка 20 допустима, 70 даёт `DAILY_LIMIT_EXCEEDED`, следующая 20 снова допустима. Расходы остаются 950.

## Примеры и границы

- Разовый максимум `500`: сумма `500` проходит, `500.01` — нет.
- Дневной максимум `1000` и расходы `900`: покупка `100` проходит, `100.01` — нет.
- При двух отказах выбирается первый по порядку правил. Число попыток само по себе не влияет на лимит.

Последовательности и конфигурации дополнительно проверяются в `tests/test_progression.py`. Прочитайте ожидаемый результат каждого сценария до реализации.

Все проверки открыты: `tests/test_contract.py` и `tests/test_review_contract.py`.
Описание объектов — в [REFERENCE.md](REFERENCE.md), исходные результаты тестов — в [STARTER-STATE.md](STARTER-STATE.md).
